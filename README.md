## 🔍프로젝트 구조
```
├── api/                # REST API 앱 (예시 모델/시리얼라이저/테스트 포함)
├── frontend/           # Django 템플릿 기반 프론트엔드 앱
├── config/             # 프로젝트 전역 설정
├── static/             # 정적 파일 (CSS/JS 등)
├── templates/          # 베이스 및 프론트엔드 템플릿
├── manage.py
├── requirements.txt
├── env.example
└── README.md
```
